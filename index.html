📥 Restore from CSV

If this device's data ever gets cleared by accident, or you're setting up a fresh phone, restore entries from a CSV you exported earlier — using the exact file this app produces (this file's own export, not the main ASSETLINE app's). Restored entries are added back as normal, fully editable entries. Rows that exactly match something already on this device are skipped automatically, so restoring the same file twice won't create duplicates.
